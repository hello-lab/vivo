# 🧠 DopaRecovery


A science-backed, AI-powered addiction recovery app designed to help users overcome unhealthy habits and dependencies. DopaRecovery combines habit tracking, personalized recovery plans, community support, and real-time interventions to guide users toward a healthier, dopamine-balanced life.

---

## 📱 Features

- 🎯 **Personalized Recovery Plans**  
  Tailored strategies for different types of addictions: internet, gambling, alcohol, nicotine.

- 📊 **Habit Tracking**  
  Track cravings, triggers, relapses, and progress with easy-to-use visual charts.

- 🤖 **AI-Powered Interventions**  
  Smart, real-time recommendations and motivational nudges based on user behavior and mood logs.

- 🧩 **Community Support**  
  Anonymous, moderated support groups and discussions for peer encouragement.

- 🗓️ **Daily Challenges & Tasks**  
  Dopamine detox activities and custom tasks to replace addictive behaviors with healthier alternatives.

- 📚 **Resource Library**  
  Expert articles, videos, and mental health guides for deeper understanding and support.

---


## 🚀 Tech Stack

- **Frontend:** React Native (Expo)
- **Backend:** Node.js, Express.js
- **AI Modules:** Gemini API
- **Authentication:** JWT & OAuth
- **Push Notifications:** Expo Push Service
